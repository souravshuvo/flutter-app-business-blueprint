# Flutter Monetization

Future reusable monetization layer for Flutter apps.

Use this folder for AdMob architecture, ad placement rules, rewarded ad flows, frequency caps, test/prod configuration, policy notes, and measurement strategy.

## Principles

- User experience before ads
- Policy compliance before revenue
- Rewarded ads for optional value exchange
- Interstitial ads only at natural transition points
- Clear separation between test and production ads
