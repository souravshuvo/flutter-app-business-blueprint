# Playbooks

Step-by-step operating procedures for repeated workflows.

Use this folder for processes that must be followed carefully, such as Firebase setup, AdMob setup, Play Store release, ASO updates, production monitoring, and app maintenance.

## Playbook Format

Each playbook should include:

- Goal
- When to use it
- Required tools or accounts
- Steps
- Common mistakes
- Verification
- Follow-up tasks
