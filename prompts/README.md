# Prompts

Reusable Codex prompts for repeatable app and game development work.

Use this folder for prompts that help with planning, feature implementation, bug fixing, refactoring, code review, testing, release preparation, and post-release analysis.

## Available Prompts

- `new-app-planning-prompt.md` - Plan a brand-new Flutter app or game before implementation.
- `existing-app-improvement-prompt-pack.md` - Improve already-published apps one by one through audit, market review, bug fixing, AdMob and analytics review, feature planning, QA, release, and learning notes.
- `existing-app-improvement-prompt-pack-v2.md` - Recommended fast version for existing apps; skips `pub get`, analysis, tests, builds, install, and emulator unless essential or explicitly requested.
- `play-store-creative-assets-prompt-pack.md` - Create Play Store screenshots, feature graphics, app icons, vector-style visuals, and preview video production packages from real app evidence.
- `game-production-ready-prompt-pack.md` - Turn a playable game prototype into a production-ready v1 with polished UI, enough content, AdMob, analytics, store assets, QA, and release readiness.
- `snake-arena-game-prompt-process.md` - Plan and build an original snake/worm arena game from concept to prototype, monetization, store assets, testing, and release.
- `bubble-shooter-game-prompt-process.md` - Plan and build an original bubble shooter game from concept to prototype, levels, boosters, monetization, store assets, testing, and release.
- `space-shooter-game-prompt-process.md` - Plan and build an original space shooter game from concept to prototype, waves, weapons, monetization, store assets, testing, and release.
- `rapid-jump-game-prompt-process.md` - Plan and build an original rapid jump arcade game from concept to prototype, platforms, missions, monetization, store assets, testing, and release.
- `crowd-control-arcade-game-prompt-process.md` - Plan and build an original Mob Control-style crowd arcade game from concept to prototype, gates, levels, monetization, store assets, testing, and release.
- `tic-tac-toe-game-prompt-process.md` - Plan and build a polished original tic tac toe game from concept to prototype, AI, variants, monetization, store assets, testing, and release.
- `match-puzzle-game-prompt-process.md` - Plan and build an original match puzzle game from concept to prototype, levels, blockers, boosters, monetization, store assets, testing, and release.
- `triple-tile-match-game-prompt-process.md` - Plan and build an original Tile Explorer-style triple tile match game from concept to prototype, levels, boosters, monetization, store assets, testing, and release.
- `water-sort-puzzle-game-prompt-process.md` - Plan and build an original water sort puzzle game from concept to prototype, levels, boosters, monetization, store assets, testing, and release.
- `farming-life-game-prompt-process.md` - Plan and build an original farming life game from concept to prototype, crops, upgrades, monetization, store assets, testing, and release.
- `arrow-puzzle-first-prototype-prompt.md` - Build the first prototype for the Arrow Puzzle game example.

## Prompt Format

Each prompt should include:

- Purpose
- When to use it
- Inputs required
- Prompt text
- Expected output
- Review checklist
