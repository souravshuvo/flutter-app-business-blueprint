# Prompts

Reusable Codex prompts for repeatable app and game development work.

Use this folder for prompts that help with planning, feature implementation, bug fixing, refactoring, code review, testing, release preparation, and post-release analysis.

## Available Prompts

- `new-app-planning-prompt.md` - Plan a brand-new Flutter app or game before implementation.
- `existing-app-improvement-prompt-pack.md` - Improve already-published apps one by one through audit, market review, bug fixing, AdMob and analytics review, feature planning, QA, release, and learning notes.
- `existing-app-improvement-prompt-pack-v2.md` - Recommended fast version for existing apps; skips `pub get`, analysis, tests, builds, install, and emulator unless essential or explicitly requested.
- `play-store-creative-assets-prompt-pack.md` - Create Play Store screenshots, feature graphics, app icons, vector-style visuals, and preview video production packages from real app evidence.
- `snake-arena-game-prompt-process.md` - Plan and build an original snake/worm arena game from concept to prototype, monetization, store assets, testing, and release.
- `arrow-puzzle-first-prototype-prompt.md` - Build the first prototype for the Arrow Puzzle game example.

## Prompt Format

Each prompt should include:

- Purpose
- When to use it
- Inputs required
- Prompt text
- Expected output
- Review checklist
