২. AdMob block paste করো · optional

AdMob-এর App ID ও ছয় ধরনের ad unit-এর লেখা, links ও image markup-সহ paste করা যাবে। Import করার পর নিচের mapping মিলিয়ে নাও। IDs খালি থাকলে test ads দিয়ে কাজ হবে; production-এ সেই format বন্ধ থাকবে।
